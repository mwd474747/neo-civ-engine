# NeoCiv Engine

Modular Godot 4 / Bevy prototype for a Civilization-inspired 4X TBS game.

## Goals
- Simplest viable core engine with deep extensibility.
- Data-driven mechanics.
- AI-agent friendly development.

## Tech Stack
- Godot 4.3+ (primary)
- GDScript + Resources
- Hex TileMap
- Data: JSON + .tres resources
